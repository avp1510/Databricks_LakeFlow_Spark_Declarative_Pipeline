# Goodcabs Transportation Pipeline

I made this using Databricks Lakeflow Spark Declarative pipeline using materialized view for block processing and streaming view for timely updating of coming data.

What could then be shared to offices depending on the city using IAM, and then BI dashboards could be generated using Genie for AI queries from the data in real-time.
